## Featured Project: The WebLang

WebLang = BTW + STW + MTWC. Replaces HTML, CSS & JS with 3 simple files. Clean syntax, short tags, learn in minutes. 🚀

### WebLang Features

- **BTW** — Base Text Web. Replaces HTML for page structure.
- **STW** — Style The Web. Replaces CSS for style.
- **MTWC** — Make The Web Click. Replaces JavaScript for logic.
- **10 languages** — A family of 10 simple languages, with a built-in IDE and docs.

## Usage

Everything lives in one file, `index.html`. No build step and no dependencies.

1. Download `index.html`.
2. Open it in any browser.

To host it on GitHub Pages:

1. Upload `index.html` to a repository.
2. Go to **Settings → Pages** and enable Pages on the main branch.
3. Your site goes live at `https://<username>.github.io/<repo>/`.
